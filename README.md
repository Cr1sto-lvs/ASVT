# ASVT
Программа предназначена_ для удобного визуального конструирования и тестирования логических схем путём перетаскивания блоков_. Она помогает пользователям легко создавать схемы, проверять их работу и получать мгновенную обратную связь.

**Основные возможности программы:**

Размещение логических элементов (AND, OR, XOR, NOT, NAND, NOR);\n
Создание входных (INPUT) и выходных (OUTPUT) блоков;\n
Простое соединение элементов между собой;\n
Свободное перемещение блоков по рабочему пространству;\n
Быстрая смена значений входных сигналов двойным кликом мыши;\n
Автоматический расчет результата схемы;\n
Генерация и отображение таблицы истинности для текущего набора условий.\n
Эта простая и интуитивно понятная среда обеспечивает удобный способ изучения и разработки цифровых схем.\n
