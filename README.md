# ASVT
Программа предназначена_ для удобного визуального конструирования и тестирования логических схем путём перетаскивания блоков_. Она помогает пользователям легко создавать схемы, проверять их работу и получать мгновенную обратную связь.

**Основные возможности программы:**

Размещение логических элементов (AND, OR, XOR, NOT, NAND, NOR);
Создание входных (INPUT) и выходных (OUTPUT) блоков;
Простое соединение элементов между собой;
Свободное перемещение блоков по рабочему пространству;
Быстрая смена значений входных сигналов двойным кликом мыши;
Автоматический расчет результата схемы;
Генерация и отображение таблицы истинности для текущего набора условий.
Эта простая и интуитивно понятная среда обеспечивает удобный способ изучения и разработки цифровых схем.
